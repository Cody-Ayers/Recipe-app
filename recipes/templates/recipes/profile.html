About this app

The Recipe Hub is a full-stack recipe manager I built to practice working across an entire application — from the database up to the interface. Users can create an account, add recipes with a photo, difficulty, and cooking time, browse and search the board, and remove recipes they no longer want.

Built with:

  • Django (Python) for the backend, models, and views
  • PostgreSQL as the production database, via psycopg2
  • Django's built-in authentication for login, sign up, and log out
  • Pandas, NumPy, and Matplotlib to power the search/reporting page
  • Pillow for handling recipe image uploads
  • Custom CSS (no framework) for the "diner board" look
  • Gunicorn and WhiteNoise, deployed on Heroku
